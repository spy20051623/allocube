# 开始使用

本章介绍注册、审核、登录和首次进入系统后的基本操作。

## 注册账号

1. 在登录页选择“申请注册账号”。
2. 填写唯一用户名、姓名、工号和符合要求的密码。
3. 如果邮件功能已启用，可填写允许域名内的邮箱并完成验证码验证。
4. 提交申请，等待系统管理员审核。

用户名和工号都可以用于登录；邮箱不用于登录。邮件关闭时不要求邮箱。邮件启用但未绑定邮箱时，仍可注册，但不能接收邮件提醒或使用邮件自助找回密码。

如果管理员退回申请，可在“用户信息”中修正资料后重新提交。待审核账号只能访问“用户信息”和“通知中心”，不能申请机器或创建占用。

## 登录

登录页支持两种方式：

- 使用用户名和密码。
- 使用已启用的工号和密码。

系统按个人设置执行无操作自动登出。遇到会话失效提示时，重新登录即可；不要在多个域名、协议或端口之间混用同一会话。

## 找回密码

邮件功能可用且账号绑定邮箱时，可从登录页申请密码重置邮件。链接一次有效，并在签发后 30 分钟到期。

没有可用邮箱时，请联系系统管理员生成一次性密码重置链接。管理员看不到原密码。

密码修改或重置会使旧网页会话失效，但不会自动吊销个人访问令牌。怀疑令牌泄露时，还应在“用户信息 → 个人访问令牌”中吊销令牌。

## 首次进入系统

### 浏览全部资源

“全部资源”列出系统中的机器、硬件说明、连接说明、标签、维护状态和你的权限状态。这里可以申请机器使用权，也可以退出不再使用的机器。

### 查看资源日历

获得机器使用权后，机器及其资源组会出现在“资源日历”中。日历支持按机器筛选、日期跳转、一天或一周视图、资源组或整机模式以及时间轴缩放。

### 检查用户信息

在右上角用户菜单打开“用户信息”，可以维护：

- 用户名、姓名、工号和邮箱。
- 密码与自动登出时长。
- 邮件通知偏好。
- 供 AI、CLI 和脚本使用的个人访问令牌。

姓名和工号修改可能需要系统管理员审核。令牌明文只在创建成功时显示一次。

## 通知

用户菜单会显示未读通知数量。通知可单条标记已读或一键全部已读，并在可能时跳转到相关机器、占用或管理页面。
