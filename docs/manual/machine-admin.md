# 机器管理员指南

机器管理员按机器授权，只能管理自己负责的机器。系统管理员可以指定或移除机器管理员。

## 权限边界

机器管理员可以查看“管理控制台”，但只会看到拥有使用权的机器；其中只有被授予管理员身份的机器可以修改。

机器管理员不能：

- 新建或永久删除机器。
- 审核系统账号注册或停用、删除用户。
- 指定其他机器管理员。
- 修改系统设置或查看系统审计记录。

## 机器信息

在“管理 → 资源管理”选择机器后，可查看机器信息、资源设置和用户与权限。具备管理权限时可以维护机器名称之外由页面允许编辑的连接说明、硬件说明、标签等信息；系统管理员保留机器级全局操作。

## 资源设置

资源模型支持：

- **编号范围**：例如逻辑核 `0–127`。
- **独立设备**：例如 GPU 0、GPU 1。
- **可切分容量**：例如 512 GiB 内存。

资源组可以组合多种资源分配。保存配置时，系统统一检查范围、重复设备、容量超限和资源组之间的冲突。修改资源配置会生成版本，既有占用保留创建时的资源快照。

进行破坏性调整前，应先查看页面展示的影响范围。不要用修改名称代替停用或维护操作。

编辑机器资料或资源配置时，未修改的表单会自动同步其他管理员的更新；已有输入时保留草稿，提交遇到版本变化才询问是否覆盖，取消则保留输入。资源配置覆盖会保留其他管理员新增、当前草稿中未包含的资源项和资源组，并重新检查整套配置的分配、容量及名称约束。维护或停用的影响范围过期时，确认后按最新范围执行；网络异常导致结果不明确时，请手动刷新核对，不要重复提交。

## 用户与权限

机器管理员可以：

- 查看机器成员和待处理使用权申请。
- 批准或拒绝这台机器的申请。
- 邀请用户成为普通成员。
- 移除普通成员。

只有系统管理员可以授予或取消机器管理员身份。移除成员前，页面会说明其占用受到的影响。

### 使用权有效期

到期日期固定按北京时间当天 24:00（次日 00:00）失效，不受浏览器时区或日历显示时区影响，列表和编辑器只显示日期。

申请列表和用户列表均显示“到期时间”。点击普通成员或待审批申请的到期时间，可以修改到期日期或选择“长期有效”；保存待审批期限不会自动批准，点击“通过申请”才按已保存期限授权。邀请用户默认授权 30 天，可修改期限或选择长期有效。

延期申请沿用待审批列表，标记“延期申请”并展示原到期日和申请日期。有限延期必须晚于原到期日，批准后才生效，且不会缩短当时已有授权。原授权到期不结束延期申请，只有申请的新期限到达才自动拒绝。拒绝或撤回不改变原授权；成员退出或被移除时，待审批延期一并结束。

缩短已加入用户的期限会自动取消完全位于截止时间之后的占用，并将跨越截止时间的占用截断到该时间；进行中占用也按此规则处理。保存结果会显示取消和截断数量。延长期限不会恢复之前调整的占用。

待审批申请到达截止时间仍未处理，系统会自动记录为审批不通过并通知申请人；原申请不能再批准或修改，需要重新申请。过期成员保留记录，但不能继续使用机器；管理员可调整期限恢复权限，已有待审批申请时应通过审批入口处理。

机器管理员始终长期有效，不能修改期限。将有限期普通成员设为机器管理员时，使用权自动改为长期有效；取消管理员身份后仍保留长期使用权，可再调整期限。上线前已有成员的长期授权保持不变。

机器使用权审核的邮件采用超时待办摘要，不会在每次申请时立即发送；等待超过 15 分钟的待办按每 30 分钟检查一次，同一申请版本对同一管理员只提醒一次。需绑定邮箱并在“用户信息 → 邮件通知”开启“超时待办”。

## 安排维护

维护可以作用于整机或指定资源组，并设置开始、结束时间和原因。提交前会预览受影响占用；根据交集，系统可能：

- 取消完全落在维护窗口内的占用。
- 裁切占用的开始或结束。
- 将跨越维护窗口的占用拆分为两个片段。

取消维护不会自动恢复此前已经取消或调整的占用。

## 释放占用

机器管理员可以取消所管理机器上的未来占用，或提前结束进行中占用。执行时应填写清晰原因；占用所有者会收到通知，操作也会进入审计记录。

官方 API 始终只能修改令牌所有者本人的占用，不会因为令牌所有者是机器管理员而允许操作他人占用。

## 统计

机器管理员可以查看有权访问机器的登记占用统计。统计基于系统登记的占用时段，不代表真实硬件利用率。

日历仅为有限授权显示北京时间到期日期，超期区域以灰色斜纹标记。拖选跨越期限时只保留期限内的时段；手动填写超期时间会提示错误。长期有效不显示到期日期。
