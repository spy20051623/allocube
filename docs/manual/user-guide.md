# 普通用户指南

普通用户可以申请机器使用权、查看资源排期，并管理自己的占用。

## 申请机器使用权

1. 打开“全部资源”。
2. 找到目标机器并查看资源摘要、维护状态和管理员信息。
3. 选择申请使用权并填写必要说明。
4. 等待机器管理员或系统管理员处理。

申请通过后，机器会出现在“资源日历”和“管理”的可见列表中。退出机器会同时失去该机器上的使用权；系统会按页面提示处理进行中和未来占用。

## 浏览排期

“资源日历”提供以下操作：

- 按机器、资源组名称或标签筛选。
- 在一天和一周视图间切换。
- 在资源组占用和整机占用模式间切换。
- 使用 6、12、24 小时时间轴缩放。
- 查看维护、停用和已有占用。

排期中的姓名和工号按系统现有规则显示；标题、用途、备注、原始时间和调整原因仅本人或对应机器管理员可见。

## 创建占用

1. 在“资源日历”选择“资源组”或“整机”。
2. 在时间轴拖动一个或多个未来时段。
3. 填写标题、用途和备注。
4. 查看预览结果并处理冲突或被拆分的时段。
5. 最终提交。

一次提交中的片段必须属于同一种占用范围。服务端会在事务中重新检查权限、时间和资源冲突；任何片段失效时，本次提交不会部分生效。

管理员配置的最短时长、最长时长和最远可占用天数会应用到每次占用。

## 修改占用

在“我的占用”或日历详情中打开本人占用：

- 未来占用可以修改时间、标题、用途和备注。
- 修改时不能更换资源组或占用范围；需要更换时应取消后重新创建。
- 进行中占用不能修改开始时间，页面只允许执行仍然有效的调整。
- 已结束或已取消占用不能修改。

编辑过程先在页面形成草稿，最终提交前不会改变服务端记录。若新时段冲突，原占用保持不变。

## 取消或提前结束

- 本人未来占用可以取消。
- 本人进行中占用可以提前结束。
- 已结束占用不能取消。

机器管理员安排维护、停用资源或释放占用时，系统可能取消、裁切或拆分相关时段，并通过通知说明结果。

## 我的占用

“我的占用”汇总未来、进行中、已结束和已取消记录。可以按状态查看详情，并从可编辑记录返回日历完成修改。

## 个人访问令牌

个人访问令牌位于“用户信息”，用于官方 API，不用于网页登录。创建时需要当前密码，可选择只读或读写权限以及有效期。

- 明文只显示一次，不应写入网页、本地存储、日志或代码仓库。
- 密码修改和重置不会吊销令牌。
- 账号停用、删除或令牌被主动吊销后，令牌立即失效。
- 不再使用的令牌应及时吊销。

完整接入方式见[官方 API](/docs/api)。
