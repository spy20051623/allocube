# 主题偏好与深色模式

## 行为

语言按钮右侧提供跟随系统、浅色、深色三个选项。图标表示用户的选择（显示器、太阳、月亮），而不是系统当前解析出的颜色。默认跟随系统，手动选择覆盖系统偏好，重新选择跟随系统后立即恢复监听。

偏好以 `allocube:theme:v1` 保存在同源 localStorage 中。刷新、登录和退出不会清除它；其他标签页通过 `storage` 事件同步，删除、清空或非法值恢复跟随系统。存储访问失败时当前页面仍可切换；`matchMedia` 不可用时系统模式回退浅色。

## 维护位置

| 文件 | 职责 |
| --- | --- |
| `public/theme-init.js` | 唯一浏览器状态实现：解析、存储、系统监听、标签页同步、订阅通知、根元素与浏览器颜色更新 |
| `index.html` | 在头部同步加载同源经典脚本，先于语言初始化、React 与路由加载 |
| `src/theme/state.ts` | 主题类型及 `useSyncExternalStore` 适配，不复制状态逻辑 |
| `src/theme/ThemeSwitcher.tsx` | 主题选项、图标和中英文文案 |
| `src/components/PreferenceMenu.tsx` | 语言与主题共用菜单、选中标记、键盘焦点和关闭行为 |
| `src/components/DisplayPreferences.tsx` | 相邻按钮装配及菜单互斥 |
| `src/theme/theme.css` | 深色语义变量、公共主题控件布局 |
| 各功能 CSS | 使用语义变量，保持功能样式的原有归属与级联顺序 |

`data-theme` 保存实际主题，`data-theme-preference` 保存用户偏好。根元素的 `color-scheme` 同时适配原生日期、时间、输入控件和滚动条，`theme-color` 跟随更新。初始化不依赖内联脚本，不修改 CSP，不引入接口、数据库字段或依赖。

主题变化只通知订阅者并修改根元素样式，不重建应用或表单，不触发业务请求。认证布局、顶栏、文档桌面及窄屏入口共用同一个状态。

## 配色规则

深色基础色：页面 `#111318`、卡片 `#1a1d24`、浮层 `#242832`、正文 `#e5e7eb`、次级文字 `#a1a8b5`、分隔边框 `#3b424f`。输入边界与焦点使用更亮的独立变量。

变量按用途划分为 `surface-*`、`text-*`、`border-*`、`fill-*`、`marker-*` 和阴影/遮罩。按钮填充色、链接文字色和装饰标记不能因原色相同而共用一个变量。组件现有浅色值保留为 `var()` 的回退值，以维持浅色视觉；新增样式应选择符合语义的角色，不添加按色值命名的变量。

日历保留资源组预约的蓝色、整机预约的紫色；自己的预约用独立层次区分，草稿保留虚线边界。维护使用橙色条纹，停用历史和阻挡/擦除使用红色，过去时段保留纹理，当前时间线使用高对比红色。预约说明文字在深色下不再降低透明度。图片与附件不做反色处理。

| 调整 | 原因 | 验证 |

| 语言和主题菜单共用外壳 | 消除相同交互的重复维护位置 | 方向键、Home/End、Enter、Escape、Tab、选中标记、焦点回归、相邻菜单互斥 |

| 文档标题锚点在键盘聚焦时显现 | 让键盘用户能看见当前可操作链接 | 与悬停共用强调文字及既有焦点环 |
| 鼠标示意图仅填充当前按键或滚轮 | 去掉覆盖左右按键的底色，保留未操作区域的透明度，避免深色下高亮与底色混在一起 | 浅深色浏览器截图对比；确认每个 SVG 仅有一个填充区域，类型检查、相关 9 项测试及生产构建通过 |
